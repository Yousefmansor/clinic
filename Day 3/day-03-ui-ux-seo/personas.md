# User Personas — Care Clinic

## Persona 1: Patient (Ahmed Mohamed)

**Age:** 32
**Role:** Patient visiting the clinic for a general consultation.
**Goals:**
- Find a good doctor quickly without calling.
- Book an appointment at a convenient time.
- See appointment history without confusion.

**Frustrations:**
- Long phone wait times.
- Not knowing which doctors are available.
- Forgetting appointment details.

**How the system helps:**
- Browse doctors by specialty.
- Pick a time slot and get instant confirmation.
- View all appointments in "My Appointments" page.

## Persona 2: Receptionist (Noura Saeed)

**Age:** 28
**Role:** Clinic receptionist managing daily appointments.
**Goals:**
- See all appointments for today in one view.
- Avoid double bookings for the same doctor.
- Update appointment status quickly.

**Frustrations:**
- Manual spreadsheets cause errors.
- Hard to track which slots are still open.
- Phone calls take too much time.

**How the system helps:**
- Dashboard shows all appointments in a table.
- Slots are limited per doctor automatically.
- Status updates with one click (Pending → Confirmed → Cancelled).
