# User Journey — Care Clinic

## Patient Journey

**Step 1: Visit the website**
Patient opens the clinic website and sees the home page with a list of available doctors.

**Step 2: Browse doctors**
Patient filters doctors by specialty and picks one.

**Step 3: Book an appointment**
Patient fills in name, phone, selects date and available time slot.

**Step 4: Confirm booking**
Patient sees a confirmation with the appointment details.

**Step 5: View appointments**
Patient can go to "My Appointments" to see all booked and past appointments.

## Admin / Receptionist Journey

**Step 1: Log in to dashboard**
Admin opens the admin dashboard after login.

**Step 2: View daily schedule**
Admin sees a table with all appointments for today, including patient name, doctor, time, and status.

**Step 3: Update appointment status**
Admin changes appointment status from Pending to Confirmed or Cancelled.

**Step 4: Manage doctors**
Admin adds new doctors, updates their specialty or status, and sets max daily slots.

**Step 5: Check availability**
Admin can see remaining slots per doctor to decide if more slots should be added.
